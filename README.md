# DPS (Document Priority Score) System

## 1. 概要
DPS (Document Priority Score) は、大量のドキュメント群の中から、業務上の重要度が高いファイルを高速に特定し、処理の優先順位を決定するためのバッチ処理システムです。

LLM による詳細な分析（Phase 1）を行う前段階として、メタデータ（更新日時、パスの深さ等）とセマンティック Embedding（Ollama）を組み合わせ、各ファイルに 0.0 〜 1.0 の重要度スコアを付与します。

## 2. 主な特徴
- **高速なランキング**: LLM による推論を行わず、Embedding のみを使用するため、大量のファイルを短時間で処理可能。
- **堅牢な変更検知**: コンテンツの SHA-256 ハッシュを記録し、内容が変更されたファイルのみを再分析する差分処理。
- **柔軟なカスタマイズ**: 環境変数（`OLLAMA_HOST`, `DPS_ALPHA` 等）により、コードを書き換えずに動作を調整可能。
- **ポータビリティ**: 分析結果に対象ディレクトリからの相対パスを使用。

## 3. 出力ファイルとその用途

分析を実行すると、対象ディレクトリ直下の `.dps/` フォルダに以下のファイルが生成されます。

| ファイル名 | 形式 | 用途 | 説明 |
| :--- | :--- | :--- | :--- |
| `rank.md` | Markdown | **人間用** | 順位、重要度、パス、トピックをまとめた読みやすいレポート。 |
| `rank.json` | JSON | **ツール用** | ランキング情報の構造化データ。可視化ツールやダッシュボードでの利用に最適。 |
| `priority_queue.jsonl` | JSONL | **システム用** | Phase 1（FastPass）等の後続プロセスが処理順序として読み込むためのリスト。 |
| `[hash].json` | JSON | **キャッシュ** | 個別ファイルの分析中間結果。ハッシュによる差分判定に使用。 |

## 4. 使い方

### 準備
Ollama が稼働している必要があります。
```bash
# 必要に応じて環境変数を設定
export OLLAMA_HOST=http://your-ollama-server:11434
```

### 実行
```bash
python -m sources.dps_runner <対象ディレクトリパス>
```
